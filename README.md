# AI Dub India

**AI-powered multilingual video dubbing platform** that converts video speech into another language using AI.

## ✨ Features

* 🎙️ AI Speech-to-Text using Gemini
* 🌐 AI-powered Translation
* 🔊 Text-to-Speech using gTTS
* 🎭 Male & Female voice styles
* 🎬 Automatic video dubbing
* ⚡ FFmpeg audio/video processing
* 🧹 Automatic temporary-file cleanup

## 🛠️ Tech Stack

**Frontend:** HTML, CSS, JavaScript, CSS

**Backend:** Python, Flask

**AI:** Google Gemini 2.5 Flash, gTTS

**Media:** FFmpeg

## 🔄 Workflow

```text
Video Upload
     ↓
Audio Extraction
     ↓
Gemini Speech-to-Text
     ↓
AI Translation
     ↓
gTTS Voice Generation
     ↓
FFmpeg Voice Processing
     ↓
Dubbed Video
```

## 🌍 Supported Languages

Hindi • English • Tamil • Telugu • Bengali • Japanese • Spanish • French • German • Korean

## 🚀 Installation

```bash
git clone https://github.com/indrakumargupta/AI_Dub_India.git
cd AI_Dub_India

pip install -r requirements.txt

python app.py
```

Open:

```text
http://127.0.0.1:5000
```

> **Requirement:** FFmpeg must be installed and available in your system PATH.

* No lip-sync
* No speaker voice cloning
* Voice styles use pitch/tempo effects
* Large videos may take longer to process
